# srh-solar

Modern, high-performance solar EPC website for **SRH Solar** (SRH Green Energy Pvt. Ltd.) built with Next.js 15, React 19, Tailwind CSS, and Motion.

## Key Features
- **Design System**: Editorial dark-forest aesthetic with lime accents, smooth typography, and Autopilot Studio-style text reveal animations on all headings.
- **Accurate Solar Calculator**: Real-time rooftop solar sizing based on monthly electricity bill / consumption, exact Rajasthan DISCOM net-metering formulas, PM Surya Ghar: Muft Bijli Yojana DBT subsidies (up to ₹78,000), 40% commercial depreciation, and 25-year cumulative savings.
- **All Core Pages**:
  - `/` - Home page with hero, impact metrics, service previews, and FAQs
  - `/about` - Company history, 4 pillars of excellence, leadership, and stats
  - `/services` - 6 detailed EPC services with schematics and specs
  - `/calculator` - Dedicated solar ROI & capacity calculator
  - `/blog` & `/blog/[slug]` - Knowledge base with SSG dynamic articles
  - `/contact` - Roof survey booking and direct WhatsApp consultation
  - `/privacy-policy` - Data governance and DISCOM net-metering privacy
  - `/terms` - Turnkey EPC conditions and 25-year equipment warranty terms
- **Mobile Responsive**: Fully responsive floating navbar with mobile drawer and optimized grid layouts.
- **Pure SVG Icons**: Clean Lucide vector icons throughout.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **UI & Components**: React 19, Tailwind CSS
- **Animations**: Motion (`motion/react`)
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
npm start
```
